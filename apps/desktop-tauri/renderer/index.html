        기본 개발 폴더

        작업 위치를 따로 지정하지 않으면 MCP가 이 폴더 아래에 새 폴더와 워크스페이스를 만듭니다. 기존 워크스페이스 이름을 지정하면 그 워크스페이스를 사용합니다.

        MCP 서버에는 Node.js가 필요합니다. PowerShell에서 node --version으로 확인하세요. 명령을 찾을 수 없으면 Node.js를 설치한 뒤 MCP 클라이언트를 다시 여세요.

        WinCMux를 실행한 상태에서 아래 명령으로 서버를 등록하세요. 연결에 TCP 포트는 필요하지 않습니다.
