# WinCMux desktop

Use the root npm scripts to build and test this Windows Tauri app.

- `renderer/` contains the xterm.js UI, prompt editor, and Tauri adapter.
- `src-tauri/` contains the Rust core, Windows desktop services, and NSIS configuration.
- `tests/` contains bridge tests and the isolated WebView2 smoke test, benchmark, and screenshot fixture.
