# WinCMux 0.2.83

Windows x64 설치 파일은 아래 **Assets**에서 받을 수 있습니다.

- 터미널 옆에 가벼운 워크스페이스 파일 뷰어를 열어 폴더 트리, 텍스트·이미지 미리보기, 파일 복사를 사용합니다.
- 파일 이름·경로 패턴과 내용을 검색하고 선택한 폴더로 범위를 좁힙니다. 새로고침해도 열린 폴더와 선택 파일이 유지됩니다.
- Git 변경을 스테이징 전·후와 새 파일로 구분하고, 색상을 적용한 diff를 표시합니다. Git 조회 시 불필요한 명령 프롬프트 창을 띄우지 않습니다.
- Agent 탭에서 실제로 있는 에이전트 관련 파일을 `.agents`, `.codex` 등 폴더별로 접고 펼쳐 확인하고, 편집 가능한 파일을 저장합니다.
- 키보드와 미리보기 화살표로 이전·다음 파일을 이동합니다.

[화면과 사용법](https://github.com/sungreong/wincmux/blob/v0.2.83/README.kr.md)

SHA-256은 배포된 설치 파일의 Release 자산 정보를 확인하세요. 코드 서명은 적용하지 않았습니다.
