## WinCMux 0.2.105

Windows x64 설치 파일은 아래 **Assets**에서 받을 수 있습니다. 설치 또는 업데이트 전에 실행 중인 WinCMux 터미널 작업을 종료해 주세요.

### 0.2.94 이후 달라진 점

- **원격 SSH**에서 Windows OpenSSH 별칭을 불러오거나 직접 연결할 수 있습니다. 연결 테스트, 저장 목록, VS Code에서 SSH 설정 열기를 지원합니다.
- **Docker 작업공간**에서 로컬 또는 SSH 서버의 실행 중인 컨테이너를 열 수 있습니다. 터미널과 파일·Git 보기는 선택한 컨테이너 폴더를 사용합니다. 작업환경 탭을 닫으면 연결된 터미널이 종료되고 컨테이너는 계속 실행됩니다.
- **터미널**은 창 높이에 맞춰 조절됩니다. 긴 출력은 pane 내부에서 스크롤되고 하단 입력창과 닫기 버튼이 화면에 남습니다. 에이전트가 작업 중이면 메시지를 순서대로 대기시키며, 제출하거나 취소한 항목은 대기열에서 바로 사라집니다.
- **알림**은 SSH와 로컬 Docker에서도 작업 완료, 입력 요청, 사용 한도를 감지합니다. 예약 알림을 설정하고 열려 있는 pane으로 바로 이동할 수 있습니다.
- **파일 보기**에서 선택한 폴더를 시작점으로 탐색하고, 좁은 폭에서도 폴더 이동과 검색을 사용할 수 있습니다.
- **로컬 MCP**에서 워크스페이스 이름과 경로로 대상을 찾고, 그룹 및 pane을 만들거나 선택할 수 있습니다.

### English summary

This release adds SSH and Docker workspaces with per-project terminals, file and Git views, and notifications. Terminal output scrolls inside the pane, so the composer stays in view. Submitted and cancelled prompts leave the queue immediately. Local MCP supports selecting workspaces by name or path and managing terminal groups and panes.
