# 파일 보기 검색 기능 기준

로컬 파일 보기의 동작을 SSH와 Docker 파일 보기에도 적용하기 위한 기준입니다. 파일 편집 기능과는 별개의 읽기 전용 화면입니다.

| 기능 | 로컬 기준 | SSH·Docker 동작 |
| --- | --- | --- |
| 파일 이름 검색 | 이름이나 상대 경로 패턴을 입력합니다. 일반 문자열은 부분 일치, `*`·`?`·`[]`는 패턴으로 처리합니다. 대소문자는 구분하지 않습니다. | 같은 입력을 제공합니다. 일반 이름은 부분 일치로, 경로 패턴은 원격 `find`의 글로브로 처리합니다. |
| 파일 내용 검색 | 내용 입력만으로 검색하거나 이름 패턴과 함께 입력해 두 조건을 모두 만족하는 파일을 찾습니다. | 같은 두 입력을 제공합니다. 내용 검색 결과에는 상대 경로, 줄 번호, 해당 줄과 일치 강조를 표시합니다. |
| 검색 범위 | 전체 작업공간 또는 선택한 폴더와 그 하위 폴더를 필터 팝업에서 고릅니다. 등록 폴더 선택 창에서는 등록한 폴더 중 하나 또는 여러 개를 체크할 수 있습니다. | 같은 조작을 제공합니다. 등록 폴더 보기에서는 체크한 폴더의 하위만 표시하고 검색합니다. |
| 제외 필터 | 폴더 및 파일 패턴을 쉼표로 구분해 입력합니다. 기본으로 `.git`, `node_modules`, `target`, `.venv`, `venv`, `dist`, `build`를 건너뜁니다. | 같은 입력과 기본 제외 폴더를 사용하고, 빌드·의존성 폴더 포함 선택을 제공합니다. |
| 확장자 필터 | 별도 모달에서 여러 확장자를 체크하고 적용합니다. 아무것도 선택하지 않으면 전체입니다. 폴더는 계속 보이고 파일 목록과 검색 결과를 함께 거릅니다. | 같은 모달을 사용합니다. 선택값은 파일 보기 화면에 저장됩니다. |
| 폴더 등록 | 파일 트리에서 폴더를 선택해 등록합니다. 완료 메시지와 등록된 폴더 표시를 보여 줍니다. 목록 위 폴더 선택 창에서 전체 또는 등록한 폴더 1개 이상을 고릅니다. | 같은 조작을 사용합니다. 등록 목록과 볼 폴더 선택값은 로컬 작업공간 또는 원격 호스트·컨테이너·작업공간 경로별로 분리해 저장합니다. |
| 검색 결과 | 파일 이름과 경로를 구분하고, 내용 검색에는 줄 번호·해당 줄·일치 강조를 표시합니다. 긴 결과는 한 줄에서 `…`로 줄이고 전체 내용은 툴팁으로 확인합니다. 결과를 누르면 파일 미리보기를 엽니다. | 같은 결과 구조와 이동을 제공합니다. |

## 구현 위치

- 로컬 화면: `apps/desktop-tauri/renderer/renderer.workspace-viewer.js`, `apps/desktop-tauri/src-tauri/src/workspace_viewer.rs`
- SSH·Docker 공통 화면: `apps/desktop-tauri/renderer/ssh-workspace.js`, `apps/desktop-tauri/src-tauri/src/ssh_viewer.rs`
- 공통 확장자 선택 상자: `apps/desktop-tauri/renderer/viewer-extension-filter.js`

## 전송과 검색 한도

로컬 검색은 최대 500개 결과, 10만 항목 또는 5초에서 일부 결과로 표시합니다. 원격 검색은 응답량을 제한하기 위해 한 번에 최대 150개 결과를 표시하며, 등록 폴더가 여러 개면 각 폴더의 검색 결과를 합쳐 150개까지 표시합니다. 내용 검색은 큰 바이너리 파일을 건너뜁니다. 한도에 걸렸을 때는 결과 제목에 일부 표시를 붙입니다.

검색과 목록은 현재 작업공간 밖의 경로를 읽지 않습니다. 등록된 폴더가 삭제되거나 접근 불가능해지면 목록에 오류를 표시하고, 사용자가 등록을 해제할 수 있습니다.

검색 입력은 이름·내용 두 줄로 유지하고, 범위·빌드 폴더 포함·확장자·제외 패턴은 `필터` 팝업에 둡니다. 팝업은 파일 트리 높이를 차지하지 않습니다. 폴더 등록 완료 메시지는 잠시 표시하고, 등록 표시와 선택 폴더 개수는 계속 보여 줍니다.

원격의 경로 패턴은 Unix `find`의 `-ipath`를 사용하므로, 로컬 glob과 비교하면 `*`가 `/`를 넘는 경우에 매칭 범위가 더 넓을 수 있습니다. 일반 파일 이름 패턴과 내용 검색은 같은 화면 흐름으로 동작합니다.

SSH 파일 목록과 미리보기는 파일 작업마다 새 명령 채널을 엽니다. 이전 구현은 명령이 시간 초과될 때 채널을 닫지 않아 서버의 세션 자리를 차지할 수 있었습니다. 현재는 시간 초과·오류 뒤 채널을 닫고, SSH 파일 작업을 순서대로 처리하며, 접힌 등록 폴더는 펼칠 때만 읽습니다. 서버가 채널을 일시적으로 거부하면 짧게 재시도합니다. 계속 거부되면 사용하지 않는 터미널을 닫고 다시 시도하거나 작업공간을 재연결하세요. 목록 오류는 목록 안에, 미리보기 오류는 미리보기 안에 다시 시도 버튼과 함께 표시합니다. 미리보기 크기 선택은 채널 개설 실패와 별개의 전송 한도지만, 큰 파일의 긴 전송은 시간 초과 가능성을 높입니다.

로컬·SSH·Docker에서 폴더를 펼치면 해당 하위 목록에, 파일을 누르면 미리보기 영역에 즉시 로딩 표시와 `aria-busy` 상태를 보여 줍니다. SSH 목록은 요청이 완료되기 전에 비워진 채로 남지 않으며, 실패하면 목록 안에 오류와 다시 불러오기 버튼을 표시합니다.
